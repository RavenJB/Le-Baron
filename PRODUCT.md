## Users

## Product Purpose

Present Jules’s work and professional profile so visitors can explore his projects and learn about him.

## Capabilities and Constraints

- Bilingual French and English experience.
- Projects are sourced from Jules’s public GitHub repositories. The site supports swipe decisions, category browsing, saved matches, and a profile section.
- The existing project uses Vite and vanilla JavaScript.
- Contact details, a profile photo, and a CV are not yet provided.
- Several profile and project descriptions are marked `[DEMO]` and need Jules’s confirmed information before they can be treated as factual.
- The portfolio’s distinctive positioning beyond presenting Jules’s work and profile has not been established.

## Evidence on Hand

- Public repository snapshot: `public/data/projects.json`.
- Project-specific category, description, message, and featured settings: `data/projects-overrides.json`.
- French and English interface and profile content: `data/translations/fr.json` and `data/translations/en.json`. Some profile and project content is explicitly marked as demo material.
- Public GitHub profile and repository links are present in the site. No contact details, profile photo, or CV are currently supplied.

## Product Principles

- Help recruiters and collaborators understand Jules’s work and professional profile.
- Make the project collection available in both French and English.
- Present work through its associated public GitHub repositories.
- Keep personal and project claims grounded in information Jules has confirmed.
